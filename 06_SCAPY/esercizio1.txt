# Avvia Scapy con i privilegi di amministratore
# sudo scapy

# 1. Creiamo il nostro primo livello: un pacchetto IP.
# Scapy compila automaticamente l'IP sorgente (il tuo PC), ma specifichiamo la destinazione.
p = IP(dst="8.8.8.8")

# 2. Vediamo un riassunto del nostro pacchetto.
p.summary()
# OUTPUT ATTESO: 'IP src=192.168.1.10 dst=8.8.8.8' (il tuo IP sarà diverso)

# 3. Ora aggiungiamo (impiliamo) un livello UDP sopra l'IP.
p = p / UDP()

# 4. Controlliamo di nuovo il riassunto. Ora include UDP.
p.summary()
# OUTPUT ATTESO: 'IP src=192.168.1.10 dst=8.8.8.8 / UDP src=domain dst=domain'

# 5. Usiamo .show() per un'analisi dettagliata di tutti i campi.
# Vedrai come Scapy ha scelto delle porte di default.
p.show()

# 6. Usiamo ls() per "listare" tutti i campi che possiamo modificare in un livello.
# È un comando utilissimo per scoprire le possibilità di Scapy.
ls(UDP)
