    
# 1. Costruiamo una richiesta DNS completa.

richiesta_dns = IP(dst="8.8.8.8") / UDP(dport=53) / DNS(qd=DNSQR(qname="unipa.it"))

# 2. Invia il pacchetto e attendi una singola risposta con sr1() (Send and Receive 1).
risposta = sr1(richiesta_dns, verbose=0)

# 3. Se abbiamo ricevuto una risposta, visualizziamola.
risposta.show()

# 4. L'informazione più importante è nella sezione "Answer" (an) del livello DNS.
# Scaviamo dentro la risposta per estrarre solo l'indirizzo IP!
# .an significa 'answer', .rdata contiene l'IP.
print(risposta[DNS].an.rdata)
